Valence is an AI-integrated full-stack learning platform designed to teach students in AP Chemistry in a more intuitive way.

This project was inspired by a survey I conducted involving 200+ students from across the U.S. What I found from these surveys was
that students committed core topics to memory once they found a way to connect them to other concepts they understood. I also
found out that successful students leveraged LLMs to make these connections.

This inspired the concept for Valence: a visual-mind-map-based application that forces students to learn AP Chemistry in a way
that prioritizes progressive disclosure, curious questions, and interconnectivity. Students start at the simplest topics and only
progress to connected nodes once they have asked the AI Tutor, Val, 5 questions that demonstrate understanding and deeper thinking.

I continue to interview users and push changes to Valence weekly. Check it out here: https://www.valenceapchem.com/
